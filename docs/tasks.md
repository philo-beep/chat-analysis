# 任务看板

**全组共同维护**：谁做完一件事，就自己改自己的那一行，不用等别人问。

状态只有四档：**待做 / 进行中 / 待验收 / 完成**。

怎么用：

1. 认领任务时，状态改成「进行中」。
2. 做完了，状态改成「待验收」，并在群里说一声。
3. 验收人按「验收方式」那一列实际做一遍，通过了才改成「完成」。
4. 「当前问题」那一列写卡住的原因，不写「暂无」以外的客套话。

交付时间开会时统一填。

## 联调三个检查点

每次由 E 按验收步骤实际操作，走不通就按分工找对应的人。

| 检查点 | 必须能实际完成 | 出问题优先找谁 |
| --- | --- | --- |
| 第一次 | 输入聊天 → 后端收到 → 页面显示示例分析结果 | 按钮、页面显示异常找 A 或 B；请求失败找 C |
| 第二次 | 输入聊天 → 调用真实模型 → 页面显示真实分析结果 | 内容乱编、字段缺失、结果无法解析找 D |
| 第三次 | 修改结果 → 保存 → 刷新 → 重新打开 → 导出 | 保存失败、记录丢失找 C |

暂时无法定位时，由 C 看一遍完整请求流程，再确定该由谁改。
