# B：结果编辑与操作面板

## 交付

- `ResultPanel.vue` 支持增删及编辑需求字段、值、对应原文 evidence、待确认问题、建议待办和回复草稿。
- 样例结果显著标黄，未标来源的旧记录提醒核对原文；待办与已确认事实分区展示。
- 保存调用 `PUT /records/{id}`，成功后调用详情接口回读；失败保留草稿并显示具体错误。
- 复制等待浏览器剪贴板写入完成后再提示，失败显示错误。
- 导出调用后端导出接口，未保存修改先保存；下载包含原文、结果、编号和时间的完整记录。
- `App.vue` 保存当前记录编号与原文，刷新后重新读取最近打开的记录，并可从历史重新打开。

## 登录态适配（2026-10-18）

- `ResultPanel` 新增 `sessionActive` 和 `sessionKey` props。A 接入时应在退出、401/会话失效、账号切换时关闭/更新会话，并清空 App 层的 `result`、`recordId`、原文和截图；重新登录后先加载该账号数据，再向面板提供结果。
- 面板在会话关闭或 key 改变时立即清除草稿和状态提示，并使之前启动的保存、详情读取及复制操作失效；失效响应不会覆盖新会话数据或重新显示旧结果。
- 保存与导出使用 A 的 `saveRecord` / `getRecord` 请求封装；导出前保存草稿，再读取完整详情 JSON 下载，不再从面板直接 `fetch` 后端 URL。
- A/C 尚未实现登录、凭据传递、401 失效通知或记录归属校验，因此新 props 暂按未登录外兼容默认值，真实登录和跨账号权限仍待集成验收。当前通过详情接口取完整 JSON，后续 A 提供统一封装的 export helper 时应切换到该 helper，以保留专用导出接口行为。

测试临时前后端进程已关闭，未改动项目原有数据库。完整模型与截图场景由后续 C/D 集成及 E 验收覆盖。
